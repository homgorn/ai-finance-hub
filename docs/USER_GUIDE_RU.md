# User Guide (RU)

## Для кого
Для обычного пользователя финансового AI-сервиса (не администратора).

## Базовый пользовательский сценарий
1. Отправляешь задачу в систему.
2. Система определяет домен (tax/insurance/compliance/etc).
3. Выбирается агент и policy-ограничения.
4. Задача попадает в очередь и обрабатывается.
5. Возвращается результат.

## Что важно знать
- Для чувствительных задач может применяться более строгий режим.
- Некоторые задачи могут быть отклонены по лимитам tenant/policy.
- Внутри есть idempotency/очередь, поэтому повторные запросы обрабатываются аккуратно.

## Что означает “статус задачи”
- `submitted`
- `routed`
- `queued`
- `processing`
- `completed`
- `failed`
- `rejected`

## Частые вопросы
- Почему задача отклонена? -> quota/budget/policy.
- Почему задержка? -> очередь и приоритеты.
